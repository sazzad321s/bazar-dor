Project Name : Bazar-Dor

Short Description : Bazar-Dor is mobile first responsive web application which is made for knowing how much price of gorcery product in local market in Bangladesh. This web application show today's update price, yesterday price, previous week's price and average or highest / lowest price of grocery product.


Technology Used: Nextjs,Tailwindcss, DaisyUi, lucide react, React-hot-toast, Better-Auth, MongoDb, chatgpt(for optimized design) and etc..

Key feature of the project: 
1. This is a responsive web application.
2. Fast Reliable application.
3. Active User Verification.
4. Grocery Price tracker.
5. Database Integrated.
